# Traceability matrix

Requirement → control in the system → evidence → latest result. Unit tests run on every pull
request (required check), so "passing" means passing on `main`. Evaluations call models and run on
demand; their latest dated results are given. `tests/unit/test_validation_pack.py` checks that
every requirement in [urs.md](urs.md) has a row here and that every test named here exists.
